# 🤖 Robot Movement Simulator

A Python project that simulates the movement of a robot on a 5 × 5 grid.

## Features
- Move the robot right, left, up, and down.
- Detect grid boundaries.
- Count successful movements.
- Track the robot's movement history.
- Display the final position.

## Technologies Used
- Python
- Python IDLE

## How to Run
1. Install Python on your computer.
2. Download `robot_simulator.py`.
3. Open the file in Python IDLE.
4. Press F5 to run the program.

## Learning Goals
This project helped me practise Python programming, conditional statements, loops, and basic robot movement logic.
